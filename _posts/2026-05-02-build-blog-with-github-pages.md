个人博客的第一步不是写出复杂的页面，而是先建立一个稳定、可持续更新的发布流程。这个站点基于 GitHub Pages、Jekyll 和 Chirpy 主题搭建，适合作为学习笔记和项目复盘的长期入口。

## 为什么选择 GitHub Pages

GitHub Pages 的优势在于简单和稳定。代码、文章和部署配置都放在同一个仓库里，更新内容时只需要提交 Markdown 文件，后续交给 GitHub Actions 或 Pages 服务完成构建和发布。

这种方式适合个人博客，因为它把维护成本控制在很低的范围内：

- 不需要单独购买服务器。
- 文章可以用 Git 做版本管理。
- 可以直接复用 GitHub 的协作、备份和自动化能力。
- 静态站点访问速度快，也更容易维护。

## Chirpy 主题带来的便利

Chirpy 是一个功能比较完整的 Jekyll 主题，默认支持分类、标签、归档、目录、深色模式和响应式布局。对于刚开始搭建博客的人来说，它能减少大量重复配置，让注意力更多放在内容本身。

当前站点会重点使用这些能力：

- 用分类组织文章主题。
- 用标签标记技术关键词。
- 用归档查看写作时间线。
- 用文章目录改善长文阅读体验。

## 内容规划

接下来我会优先补充三类内容：

1. 博客搭建过程：记录从仓库初始化、主题配置到发布上线的步骤。
2. Git 和 GitHub 使用：整理常用命令、远程仓库同步和问题排查。
3. 开发工具实践：记录 Cursor、命令行、自动化脚本等日常工具的使用经验。

## 小结

博客搭建只是开始。真正有价值的是持续把实践过程写下来，形成可以回顾、可以复用、也可以继续迭代的知识库。
