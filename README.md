# GitHub Pages 个人博客

这是一个可直接部署到 GitHub Pages 的 Jekyll 博客模板。

## 使用方式

1. 创建仓库：`你的用户名.github.io`
2. 把当前目录文件推送到该仓库 `main` 分支
3. 在 GitHub 仓库 `Settings -> Pages` 中选择：
   - Source: `Deploy from a branch`
   - Branch: `main` / `(root)`
4. 等待 1-3 分钟后访问：`https://你的用户名.github.io`

## 写文章

在 `_posts` 下新增文件，命名格式：

`YYYY-MM-DD-文章标题.md`
